# V63 — Acta de partido premium

Basada en V62.

## Cambio principal
Se rediseñó completamente la generación del acta de partido para que deje de ser un documento de texto plano y tenga una presentación profesional coherente con la identidad visual de la plataforma:

- Cabecera oscura estilo plataforma.
- Logo del torneo.
- Nombre y temporada.
- Estado FINALIZADO.
- Fase/jornada, fecha, hora, grupo y ubicación cuando existen.
- Marcador central destacado.
- Logos de los dos equipos cuando están registrados.
- Resumen de goles, amarillas y rojas.
- Cronología visual de eventos.
- Bloques de firma para local, árbitro y visitante.
- Pie institucional.
- Diseño A4 optimizado para imprimir o Guardar como PDF.
- Responsive para consulta en pantalla.

No se modifican datos de partidos ni eventos en Firebase.
